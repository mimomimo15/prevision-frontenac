      Comment c’est calculé

      Pour chaque jour, « prévu » est la prévision que le modèle émettait k jours plus tôt, avec les seules données disponibles ce jour-là (rejeu, sans l’ajustement intrajournalier). Depuis le 9 novembre 2026, la prévision SPINE archivée le même jour est comparée elle aussi, et le rejeu utilise le modèle v3 dès que ses variables supplémentaires (Hull, Lanoraie, Richelieu, Varennes, CMI, heures 12–18 h) sont archivées. La période 2019–2024 a servi à calibrer le modèle (comparaison partiellement optimiste) ; 2025 et le direct sont indépendants. Vert : écart dans la tolérance choisie ; gris : jusqu’au double ; rouge : au-delà.
